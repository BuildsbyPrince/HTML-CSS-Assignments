# Task 6: Build a Basic HTML Page with a Title and Headings

**What I Did:** I created a basic HTML5 page using the `<title>` tag and a clear heading hierarchy (`<h1>` to `<h4>`).

**My Code (`task6.html`):**
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First HTML Page</title>
</head>
<body>
  <h1>Main Page Heading (H1)</h1>
  <h2>Major Section Heading (H2)</h2>
  <h3>Sub-section Heading (H3)</h3>
  <h4>Minor Heading (H4)</h4>
</body>
</html>
```
