# Task 3: Short Terminal-Navigation Practice Sheet

**What I Did:** I practiced navigating directories and creating files using basic terminal commands.

**Commands I Used:**
```bash
pwd                  # 1. Checked my current working directory
ls                   # 2. Listed all files and folders in my current directory
mkdir my-project     # 3. Created a new folder named "my-project"
cd my-project        # 4. Moved inside the "my-project" folder
touch index.html     # 5. Created an empty file named "index.html"
cd ..                # 6. Moved back up one folder level
```
