# HTML-CSS-Assignments
This repository is created as part of my college web development coursework. It demonstrates practical hands-on skills in building structured, accessible, and responsive web pages from scratch using pure HTML and CSS.
# Assignment
​This college practical assignment consists of 45 hands-on HTML and CSS tasks to learn web development from basic setup to responsive design.

# About Project
​It covers building web pages from scratch, including semantic HTML, forms, and tables, along with CSS styling, Box Model, Flexbox, CSS Grid, and a fully responsive landing page.

# Technology Used
​HTML: Used for creating the webpage structure, semantic layout, forms, tables, lists, and media.
​CSS: Used for styling, colors, typography, Box Model, Flexbox, CSS Grid, and responsive media queries.
