# Task 1: Explain What Happens Between Typing a URL and Seeing the Page

**What I Did:** I wrote a one-paragraph explanation of the browser request-response cycle from typing a URL to rendering the webpage.

**My Explanation:**
> When I type a URL into my browser and press Enter, the browser first contacts a DNS (Domain Name System) server to translate the human-readable domain name (such as `example.com`) into the server's numerical IP address. Next, the browser establishes a TCP/IP connection with that web server and sends an HTTP/HTTPS request asking for the webpage's files. The server processes the request and sends back an HTTP response containing the HTML, CSS, JavaScript, and media files. Finally, the browser parses the HTML to build the Document Object Model (DOM), applies the CSS rules to create the render tree, executes any JavaScript, and paints the visual webpage onto my screen.
