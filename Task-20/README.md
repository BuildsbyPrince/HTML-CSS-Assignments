# Task 20: Submit the Complete Multi-Page HTML Project (Home, About, Registration, Contact)

**What I Did:** I built a complete 4-page HTML project (`index.html`, `about.html`, `register.html`, and `contact.html`) linked together with a shared navigation bar.

**1. `index.html` (Home):**
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Home - Student Portal</title>
</head>
<body>
  <nav>
    <a href="index.html">Home</a> |
    <a href="about.html">About</a> |
    <a href="register.html">Registration</a> |
    <a href="contact.html">Contact</a>
  </nav>

  <p>This is the home page of my multi-page HTML project.</p>
</body>
</html>
```
