# Task 5: Share the Pushed GitHub Repository Link

**What I Did:** I linked my local Git repository to my remote GitHub repository and pushed all of my commits to the `main` branch.

**Commands I Used:**
```bash
git branch -M main
git remote add origin https://github.com/my-username/my-repo-name.git
git push -u origin main
```
**My Repository Link:**
`https://github.com/my-username/my-repo-name`
